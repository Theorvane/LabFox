# Distribution

LabFox is free to download and use on Android, iOS, Windows, and macOS. Every
LabFox feature is available on every supported platform without an in-app
purchase, subscription, account with LabFox, or advertisement. The Flutter app
contains no purchase or advertising SDK, and it does not read a store
entitlement or an advertising identifier.

GitLab itself still enforces instance permissions, project configuration, and
server-tier requirements. Free LabFox access cannot unlock a GitLab feature
that the connected instance does not provide or that the user may not operate.

The source is Apache-2.0 licensed. The LabFox name and logo remain outside the
source license under the trademark policy. Windows is distributed directly;
mobile and macOS releases use their respective stores. The shared Flutter
codebase keeps feature behavior aligned across platforms.

Store declarations, listing copy, and privacy notices must describe the
current ad-free, purchase-free build. Historical purchase records, if any,
are managed in the store consoles; removing purchase code does not cancel a
store transaction or refund a customer.
