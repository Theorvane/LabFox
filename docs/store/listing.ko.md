# 스토어 등록 문구 (한국어)

`listing.md`의 한국어 번역입니다. 영어 원본이 바뀌면 이 문구도 갱신합니다.
LabFox는 GitLab의 비공식 클라이언트이며, 제공하지 않는 기능을 약속하지 않습니다.

## 앱 이름

```
LabFox
```

## 부제 (App Store, 30자)

```
GitLab 머지 리퀘스트와 CI
```

## 짧은 설명 (Play, 80자)

```
GitLab 머지 리퀘스트를 리뷰하고 파이프라인과 잡 로그를 확인하세요.
```

## 전체 설명

```
출퇴근길에 머지 리퀘스트를 리뷰하고, 자리에 앉기 전에 파이프라인이 왜 실패했는지
확인하세요. LabFox는 자주 쓰는 GitLab 작업을 휴대폰에서 편하게 처리하도록 돕습니다.

할 수 있는 일

• 설명, 라벨, 승인 현황, 토론과 함께 머지 리퀘스트 확인
• 줄 번호와 변경 라인 강조로 파일별 diff 리뷰
• 승인, 머지, 댓글 작성
• 파이프라인 상태 확인과 색상이 유지된 잡 로그 열람
• 잡 재시도, 취소, 수동 잡 실행
• 이슈, 할 일 목록, 프로젝트 검색
• 저장소, 브랜치, 커밋, 파일 탐색
• 자체 호스팅 인스턴스를 포함한 여러 GitLab 계정 연결
• 백그라운드 할 일 확인과 제한 없는 즐겨찾기

Android, iOS, Windows, macOS에서 LabFox의 모든 기능을 무료로 사용할 수 있습니다.
광고와 앱 내 구매가 없습니다. 기능 사용 권한과 서버 요금제는 연결된 GitLab
인스턴스의 설정을 따릅니다.

화면 크기에 맞춰 휴대폰에서는 집중할 수 있는 단일 화면을, 태블릿과 데스크톱에서는
넓은 화면을 제공합니다. gitlab.com이나 회사 인스턴스에 개인 액세스 토큰으로
로그인하세요. 지원되는 플랫폼에서는 OAuth도 사용할 수 있습니다.

토큰은 기기의 보안 저장소에 보관됩니다. LabFox 계정이나 중간 서버 없이 앱이
GitLab 인스턴스와 직접 통신합니다. 익명 제품 분석은 개인정보처리방침에 설명되어
있습니다.

LabFox는 Apache-2.0 오픈소스입니다:
github.com/theorvane/labfox

개인정보처리방침: https://www.sloki9637.com/privacy

LabFox는 비공식 서드파티 클라이언트입니다. GitLab Inc.와 제휴 관계가 없으며
보증이나 인증을 받지 않았습니다. "GitLab"은 GitLab Inc.의 상표입니다.
```

## 키워드 (App Store, 100자)

```
깃랩,gitlab,머지리퀘스트,코드리뷰,CI,CD,파이프라인,데브옵스,git,저장소,자체호스팅,이슈,diff
```

스토어의 개인정보 및 데이터 사용 신고도 `PRIVACY.md`와 일치해야 합니다.
앱은 익명 제품 분석을 사용하며 광고, 광고 식별자, 앱 내 구매를 사용하지 않습니다.
